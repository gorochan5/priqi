#### `spacing`

```rust
pub fn spacing(self, spacing: impl Into<Pixels>) -> Self
```

Sets whether the [`Scrollbar`](struct.Scrollbar.md) should be embedded in the [`Scrollable`](struct.Scrollable.md), using the given spacing between itself and the contents.

An embedded [`Scrollbar`](struct.Scrollbar.md) will always be displayed, will take layout space, and will not float over the contents.

#### `padding`

```rust
pub fn padding(self, padding: impl Into<Pixels>) -> Self
```

Sets the padding of the [`Scrollbar`](struct.Scrollbar.md).

The padding is added at the top and bottom of the scrollbar (or at the left and right ends for a horizontal [`Scrollbar`](struct.Scrollbar.md)) when it is visible.

Unlike [`Self::margin`](struct.Scrollbar.md) and [`Self::spacing`](struct.Scrollbar.md), the padding does not affect the layout of the [`Scrollable`](struct.Scrollable.md).
