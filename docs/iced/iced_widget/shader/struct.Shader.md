# `iced_widget::shader::Shader`

```rust
pub struct Shader<Message, P: Program<Message>> { /* private fields */ }
```

A widget which can render custom shaders with Iced’s `wgpu` backend.

Must be initialized with a [`Program`](trait.Program.md), which describes the internal widget state & how its [`Program::Primitive`](trait.Program.md)s are drawn.
