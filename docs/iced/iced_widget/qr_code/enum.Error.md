# `iced_widget::qr_code::Error`

```rust
pub enum Error {
    DataTooLong,
    InvalidVersion,
    UnsupportedCharacterSet,
    InvalidEciDesignator,
    InvalidCharacter,
}
```

An error that occurred when building a [`Data`](struct.Data.md) for a [`QRCode`](struct.QRCode.md).

**Source:** [qr_code.rs](../../src/iced_widget/qr_code.rs.md) (lines 315-343)

## Variants

### `DataTooLong`

The data is too long to encode in a QR code for the chosen [`Version`](enum.Version.md).

### `InvalidVersion`

The chosen [`Version`](enum.Version.md) and [`ErrorCorrection`](enum.ErrorCorrection.md) combination is invalid.

### `UnsupportedCharacterSet`

One or more characters in the provided data are not supported by the chosen [`Version`](enum.Version.md).

### `InvalidEciDesignator`

The chosen ECI designator is invalid. A valid designator should be between 0 and 999999.

### `InvalidCharacter`

A character that does not belong to the character set was found.
