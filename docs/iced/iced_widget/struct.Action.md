# `iced_widget::Action`

```rust
pub struct Action<Message> { /* private fields */ }
```

A runtime action that can be performed by some widgets.

**Source:** [action.rs](../src/iced_widget/action.rs.md) (lines 7-11)

## Methods

### `impl<Message> Action<Message>`

#### `none`

```rust
pub fn none() -> Self
```

Creates an [`Action`](struct.Action.md) that does nothing.

#### `capture`

```rust
pub fn capture() -> Self
```

Creates a new “capturing” [`Action`](struct.Action.md). A capturing [`Action`](struct.Action.md) will make other widgets consider it final and prevent further processing.

Prevents “event bubbling”.

#### `publish`

```rust
pub fn publish(message: Message) -> Self
```

Creates a new [`Action`](struct.Action.md) that publishes the given `Message` for the application to handle.

Publishing a `Message` always produces a redraw.

#### `request_redraw`

```rust
pub fn request_redraw() -> Self
```

Creates a new [`Action`](struct.Action.md) that requests a redraw to happen as soon as possible; without publishing any `Message`.

#### `request_redraw_at`

```rust
pub fn request_redraw_at(at: Instant) -> Self
```

Creates a new [`Action`](struct.Action.md) that requests a redraw to happen at the given [`Instant`](https://doc.rust-lang.org/nightly/std/time/struct.Instant.html); without publishing any `Message`.

This can be useful to efficiently animate content, like a blinking caret on a text input.

#### `and_capture`

```rust
pub fn and_capture(self) -> Self
```

Marks the [`Action`](struct.Action.md) as “capturing”. See [`Self::capture`](struct.Action.md).

#### `and_request_redraw_at`

```rust
pub fn and_request_redraw_at(self, at: Instant) -> Self
```

Requests a redraw at the given [`Instant`](https://doc.rust-lang.org/nightly/std/time/struct.Instant.html). See [`Self::request_redraw_at`](struct.Action.md).

#### `into_inner`

```rust
pub fn into_inner(self) -> (Option<Message>, RedrawRequest, Status)
```

Converts the [`Action`](struct.Action.md) into its internal parts.

This method is meant to be used by runtimes, libraries, or internal widget implementations.
