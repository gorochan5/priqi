# Documentation index

Structured Markdown mirror of <https://docs.iced.rs/iced/>.

Each crate keeps the original module tree. Every page starts with YAML frontmatter and
`# crate::module::Item` as its first heading.

## Crates

- [`futures_core`](futures_core/index.md) — Core traits and types for asynchronous operations in Rust.
- [`iced`](iced/index.md) — iced is a cross-platform GUI library focused on simplicity and type-safety. Inspired by Elm.
- [`iced_beacon`](iced_beacon/index.md) — API documentation for the Rust `iced_beacon` crate.
- [`iced_core`](iced_core/index.md) — The core library of Iced.
- [`iced_debug`](iced_debug/index.md) — API documentation for the Rust `iced_debug` crate.
- [`iced_devtools`](iced_devtools/index.md) — API documentation for the Rust `iced_devtools` crate.
- [`iced_futures`](iced_futures/index.md) — Asynchronous tasks for GUI programming, inspired by Elm.
- [`iced_graphics`](iced_graphics/index.md) — A bunch of backend-agnostic types that can be leveraged to build a renderer for `iced`.
- [`iced_highlighter`](iced_highlighter/index.md) — A syntax highlighter for iced.
- [`iced_renderer`](iced_renderer/index.md) — The official renderer for iced.
- [`iced_runtime`](iced_runtime/index.md) — A renderer-agnostic native GUI runtime.
- [`iced_test`](iced_test/index.md) — Test your `iced` applications in headless mode.
- [`iced_tiny_skia`](iced_tiny_skia/index.md) — API documentation for the Rust `iced_tiny_skia` crate.
- [`iced_wgpu`](iced_wgpu/index.md) — A `wgpu` renderer for Iced.
- [`iced_widget`](iced_widget/index.md) — Use the built-in widgets or create your own.
- [`iced_winit`](iced_winit/index.md) — A windowing shell for Iced, on top of `winit`.
