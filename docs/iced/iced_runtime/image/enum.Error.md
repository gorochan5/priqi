# `iced_runtime::image::Error`

```rust
pub enum Error {
    Invalid(Arc<dyn Error + Sync + Send>),
    Inaccessible(Arc<Error>),
    Unsupported,
    Empty,
    OutOfMemory,
}
```

An image loading error.

## Variants

### `Invalid(Arc<dyn Error + Sync + Send>)`

The image data was invalid or could not be decoded.

### `Inaccessible(Arc<Error>)`

The image file was not found.

### `Unsupported`

Loading images is unsupported.

### `Empty`

The image is empty.

### `OutOfMemory`

Not enough memory to allocate the image.
