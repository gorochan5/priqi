# `iced_runtime::widget::operation::text`

Operations for widgets that contain text.

## Functions

- [`deselect`](fn.deselect.md) — Deselects any selected text.
- [`select`](fn.select.md) — Selects text between the given positions in layout coordinates.
- [`select_all`](fn.select_all.md) — Selects all text in the widget with the given [`Id`].
