# `iced_runtime::user_interface::Change`

```rust
pub enum Change {
    None,
    Overlay,
    Layout,
}
```

The change experienced by a [`UserInterface`](struct.UserInterface.md) while being updated.

**Source:** [user_interface.rs](../../src/iced_runtime/user_interface.rs.md) (lines 707-714)

## Variants

### `None`

Nothing was invalidated: the [`UserInterface`](struct.UserInterface.md) is unchanged.

### `Overlay`

Only the application overlays were recreated.

### `Layout`

The application layout was recomputed.
