# `iced_futures::backend`

The underlying implementations of the `iced_futures` contract!

## Modules

- [`default`](default/index.md) — A default, cross-platform backend.
- [`native`](native/index.md) *(Non-WebAssembly)* — Backends that are only available in native platforms: Windows, macOS, or Linux.
- [`null`](null/index.md) — A backend that does nothing!
