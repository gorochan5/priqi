# `iced::widget::markdown::Item`

```rust
pub enum Item {
    Heading(HeadingLevel, Text),
    Paragraph(Text),
    CodeBlock {
        language: Option<String>,
        code: String,
        lines: Vec<Text>,
    },
    List {
        start: Option<u64>,
        bullets: Vec<Bullet>,
    },

        url: String,
        title: String,
        alt: Text,
    },
    Quote(Vec<Item>),
    Rule,
    Table {
        columns: Vec<Column>,
        rows: Vec<Row>,
    },
}
```

A Markdown item.

## Variants

### `Heading(HeadingLevel, Text)`

A heading.

### `Paragraph(Text)`

A paragraph.

### `CodeBlock`

A code block.

You can enable the `highlighter` feature for syntax highlighting.

**Fields**

- `language: Option<String>` — The language of the code block, if any.
- `code: String` — The raw code of the code block.
- `lines: Vec<Text>` — The styled lines of text in the code block.

### `List`

A list.

**Fields**

- `start: Option<u64>` — The first number of the list, if it is ordered.
- `bullets: Vec<Bullet>` — The items of the list.

### `Image`

An image.

**Fields**

- `url: String` — The destination URL of the image.
- `title: String` — The title of the image.
- `alt: Text` — The alternative text of the image.

### `Quote(Vec<Item>)`

A quote.

### `Rule`

A horizontal separator.

### `Table`

A table.

**Fields**

- `columns: Vec<Column>` — The columns of the table.
- `rows: Vec<Row>` — The rows of the table.
