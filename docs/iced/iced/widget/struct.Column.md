# `iced::widget::Column`

```rust
pub struct Column<W> { /* private fields */ }
```

A container that distributes its contents vertically.

## Example

```rust
use iced::widget::{button, column};

#[derive(Debug, Clone)]
enum Message {
    // ...
}

fn view(state: &State) -> impl Widget<Message> {
    column![
        "I am on top!",
        button("I am in the center!"),
        "I am below.",
    ]
}
```
