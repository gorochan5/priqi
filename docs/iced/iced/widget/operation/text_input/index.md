# `iced::widget::operation::text_input`

Operations for widgets that can be used for text input.

## Functions

- [`move_cursor_to`](fn.move_cursor_to.md) — Moves the cursor of the widget with the given [`Id`](../../struct.Id.md) to the provided position.
- [`move_cursor_to_end`](fn.move_cursor_to_end.md) — Moves the cursor of the widget with the given [`Id`](../../struct.Id.md) to the end.
- [`move_cursor_to_front`](fn.move_cursor_to_front.md) — Moves the cursor of the widget with the given [`Id`](../../struct.Id.md) to the front.
- [`select_all`](fn.select_all.md) — Selects all the content of the widget with the given [`Id`](../../struct.Id.md).
- [`select_range`](fn.select_range.md) — Selects the given content range of the widget with the given [`Id`](../../struct.Id.md).
