# `iced::color`

Manage colors in different color spaces.

## Structs

- [`Color`](struct.Color.md) — A color in the `sRGB` color space.
- [`Oklch`](struct.Oklch.md) — A color in the [Oklab color space](https://en.wikipedia.org/wiki/Oklab_color_space), represented as Oklch.

## Enums

- [`ParseError`](enum.ParseError.md) — An error which can be returned when parsing color from an RGB hexadecimal string.
