# `iced_core::mouse::ScrollDelta`

```rust
pub enum ScrollDelta {
    Lines {
        x: f32,
        y: f32,
    },
    Pixels {
        x: f32,
        y: f32,
    },
}
```

A scroll movement.

**Source:** [event.rs](../../src/iced_core/mouse/event.rs.md) (lines 40-56)

## Variants

### `Lines`

A line-based scroll movement

**Fields**

- `x: f32` — The number of horizontal lines scrolled
- `y: f32` — The number of vertical lines scrolled

### `Pixels`

A pixel-based scroll movement

**Fields**

- `x: f32` — The number of horizontal pixels scrolled
- `y: f32` — The number of vertical pixels scrolled
