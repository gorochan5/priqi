# `iced_core::length::Constraint`

```rust
pub enum Constraint {
    Min(f32),
    Max,
}
```

The limit of a [`Fluid`](enum.Length.md) length.

**Source:** [length.rs](../../src/iced_core/length.rs.md) (lines 46-52)

## Variants

### `Min(f32)`

Fill available space, but never shrinks below the given amount.

### `Max`

Fill available space, but never beyond the size the element resolves to on its own; releasing any share it doesn’t use back to its siblings.
