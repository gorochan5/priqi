# `iced_core::window::RedrawRequest`

```rust
pub enum RedrawRequest {
    NextFrame,
    At(Instant),
    Wait,
}
```

## Variants

### `NextFrame`

### `At(Instant)`

Redraw at the given time.

### `Wait`
