# `iced_core::backend::Api`

```rust
pub enum Api {
    Best,
    Vulkan,
    Metal,
    DirectX12,
    OpenGL,
    WebGPU,
}
```

A hardware graphics API.

**Source:** [backend.rs](../../src/iced_core/backend.rs.md) (lines 84-98)

## Variants

### `Best`

Auto-detect and choose the best available graphics [`Api`](enum.Api.md).

### `Vulkan`

Vulkan API (Windows, Linux, Android, MacOS via vulkan-portability/MoltenVK)

### `Metal`

Metal API (Apple platforms)

### `DirectX12`

Direct3D-12 (Windows)

### `OpenGL`

OpenGL 3.3+ (Windows), OpenGL ES 3.0+ (Linux, Android, MacOS via Angle), and WebGL2

### `WebGPU`

WebGPU (Web Browser)
