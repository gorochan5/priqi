# `iced_core::keyboard::key::Physical`

```rust
pub enum Physical {
    Code(Code),
    Unidentified(NativeCode),
}
```

Represents the location of a physical key.

This type is a superset of [`Code`](enum.Code.md), including an [`Unidentified`](enum.Physical.md) variant.

**Source:** [key.rs](../../../src/iced_core/keyboard/key.rs.md) (lines 1325-1334)

## Variants

### `Code(Code)`

A known key code

### `Unidentified(NativeCode)`

This variant is used when the key cannot be translated to a [`Code`](enum.Code.md)

The native keycode is provided (if available) so you’re able to more reliably match key-press and key-release events by hashing the [`Physical`](enum.Physical.md) key. It is also possible to use this for keybinds for non-standard keys, but such keybinds are tied to a given platform.
