# `iced_graphics::geometry::fill::Rule`

```rust
pub enum Rule {
    NonZero,
    EvenOdd,
}
```

The fill rule defines how to determine what is inside and what is outside of a shape.

See the [SVG specification](https://www.w3.org/TR/SVG/painting.html#FillRuleProperty).
