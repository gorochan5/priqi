# `iced_graphics::compositor::SurfaceError`

```rust
pub enum SurfaceError {
    Timeout,
    Outdated,
    Lost,
    OutOfMemory,
    Occluded,
    Other,
}
```

Result of an unsuccessful call to [`Compositor::present`](trait.Compositor.md).

**Source:** [compositor.rs](../../src/iced_graphics/compositor.rs.md) (lines 126-145)

## Variants

### `Timeout`

A timeout was encountered while trying to acquire the next frame.

### `Outdated`

The underlying surface has changed, and therefore the surface must be updated.

### `Lost`

The swap chain has been lost and needs to be recreated.

### `OutOfMemory`

There is no more memory left to allocate a new frame.

### `Occluded`

The surface is occluded and must not be drawn to.

### `Other`

Acquiring a texture failed with a generic error.
