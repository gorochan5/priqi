# `iced_test::emulator::Mode`

```rust
pub enum Mode {
    Zen,
    Patient,
    Immediate,
}
```

The strategy used by an [`Emulator`](struct.Emulator.md) when waiting for tasks to finish.

A [`Mode`](enum.Mode.md) can be used to make an [`Emulator`](struct.Emulator.md) wait for side effects to finish before continuing execution.

**Source:** [emulator.rs](../../src/iced_test/emulator.rs.md) (lines 538-549)

## Variants

### `Zen`

Waits for all tasks spawned by an [`Instruction`](../instruction/enum.Instruction.md), as well as all tasks indirectly spawned by the the results of those tasks.

This is the default.

### `Patient`

Waits only for the tasks directly spawned by an [`Instruction`](../instruction/enum.Instruction.md).

### `Immediate`

Never waits for any tasks to finish.
